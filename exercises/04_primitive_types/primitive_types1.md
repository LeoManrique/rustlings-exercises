# The Boolean Type

A Boolean type in Rust has two possible values: `true` and `false`. Booleans are one byte in size. The Boolean type in Rust is specified using `bool`. The main way to use Boolean values is through conditionals, such as an `if` expression.

```rust
let t = true;
let f: bool = false;

if t {
    println!("t is true");
}
```
